# Eviction Notice
Eviction Notice is a fully-featured apartment rent system for Cyberpunk 2077 with new characters to meet (via text) and lightweight quest content.

## Documentation
Please see the [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/23187) page.

## Getting Started
### Requirements
Cyberpunk 2077 2.3+. The mod is Phantom Liberty-aware but the expansion is not required.

[Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511) 0.5.28+

[Red4Ext](https://www.nexusmods.com/cyberpunk2077/mods/2380) 1.28.0+

[ArchiveXL](https://www.nexusmods.com/cyberpunk2077/mods/4198) 1.24.0+

[TweakXL](https://www.nexusmods.com/cyberpunk2077/mods/4197) 1.11.0+

[Codeware](https://www.nexusmods.com/cyberpunk2077/mods/7780) 1.17.0+

[Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885) 0.2.21+

### Installation
Extract the release archive `Eviction Notice-x.x-for-x.x.zip` into the Cyberpunk 2077 directory.

Or, install the release archive using Vortex.

Or, install the mod directly from the [Eviction Notice Nexus Mods page](https://www.nexusmods.com/cyberpunk2077/mods/23187).

### Uninstallation
Toggle **Enable Eviction Notice** to **Off** in the Eviction Notice Mod Settings Menu. Verify that you have access to your apartments, and save your game. You may then exit the game and uninstall the mod. You should continue to have access to rented apartments when loading this save game again.
